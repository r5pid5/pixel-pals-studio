# 의상 허리·밑면 연결 수정

사용자가 첨부한 멜빵옷의 갈라진 앞판·양옆과 교복의 흰 허리 띠를 실제 코드로 같은 아래 각도에서 재현했습니다. 이전 검사 60개는 이 결함을 검출하지 못했습니다. [수정 전 실제 렌더](clothing-waist-before-2026-10-03.png)와 [수정 후 같은 구도](clothing-waist-sewn-2026-10-03.png)를 함께 보관합니다.

## 변경

멜빵옷은 셔츠에 투영하던 별도 앞판 하단을 제거하고 앞·뒤 몸판, 허리, 가랑이와 두 바짓통이 이어진 하나의 `OverallShell`로 구성합니다. 교복을 포함한 바지 6종도 바짓통 두 개만 붙이던 방식에서 하나의 허리와 연결된 가랑이를 갖는 표면으로 바꿨습니다. 허리는 몸통을 따르고 다리로 내려갈수록 다리 본으로 부드럽게 연결됩니다. 죄수복의 줄무늬는 별도 원통 대신 같은 바지의 면을 나누어 적용합니다.

교복·멜빵옷의 안쪽 셔츠는 바지 허리 아래로 나오지 않도록 끝납니다. 옷에 가려진 허벅지 피부는 제외하고 바지 끝 안쪽에 작은 겹침을 남깁니다. 보이는 발은 원래 형상을 유지하며 옷을 벗으면 전체 다리도 복원됩니다. 몸통·다리 크기가 작은 경우 옆면에 피부가 뚫고 나오던 문제와 의상 전환의 캐시도 검사합니다. 멜빵옷 주머니와 봉제선은 새 몸판의 실제 삼각형 위에 놓아 천 안으로 들어가지 않게 했습니다. 앞치마 끝도 셔츠 범위 안에 놓고 곡면 분할을 촘촘하게 했습니다.

의상을 바꾼 직후 내보내기를 누르면 60ms 뒤로 예약된 모델 생성보다 저장이 먼저 실행될 수 있었습니다. PNG·GLB·PMX·녹화 전에 대기 중인 의상 생성을 완료해 현재 선택과 같은 모델을 저장합니다.

## 확인한 조건

자동 검사 65개 통과. 새 `tests/trouser-surface.test.mjs`의 5개 검사는 다음을 확인합니다.

- 바지 6종이 하나의 연결된 표면이고, 추가로 찢어진 경계 없이 허리/몸판 위쪽과 두 바지 끝만 열려 있음. 면 방향과 스킨 가중치도 확인.
- 정지·걷기·춤·차 마시기·책 읽기의 4개 시간 표본에서 같은 봉제선의 정점이 벌어지지 않음.
- 멜빵옷·교복의 허리를 아래 8방향에서 확인해 셔츠나 피부가 먼저 드러나지 않음.
- 가려진 허벅지 제외, 보이는 발 유지와 옷을 벗은 뒤 다리 복원.
- 세 체형에서 멜빵옷 주머니의 앞면 전체가 몸판 밖에 놓임.

체형은 몸통/다리 `(0.75, 0.65)`, `(1.2, 1)`, `(1.35, 1.45)`입니다. 실제 Edge·WebGL에서 의상 18종의 아래 정면·옆·뒤 54장, 두 의상의 확대 4장, 멜빵옷·교복의 세 체형·6개 자세·3개 아래 각도 108장을 렌더했습니다. 모션 확인 시 돗자리·책 등은 숨겨 의상 연결부가 가려지지 않게 합니다.
