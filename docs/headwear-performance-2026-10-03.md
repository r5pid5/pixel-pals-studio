# 후드·안경·잠옷 모자 및 화면 멈춤 수정

## 실제 형태

후드는 얼굴 바깥에 여유를 두고 둘러지는 하나의 연속 곡면입니다. 얼굴 삼각형에 맞추던 투영과 아래쪽 광선 보정, 정수리를 따로 메우던 면을 제거했습니다. 완만한 윗선, 이어지는 옆선, 둥근 아래 모서리와 얼굴 개구부를 별도의 곡선으로 정의합니다. 얼굴 둘레에서 뒤통수로 이어지는 곡면의 뒤쪽을 닫으며 정수리의 파임과 패널 구분선을 만들지 않습니다. 목 주변의 작은 영역은 몸통 본을 따르고 넓은 후드 영역은 머리 본을 따릅니다. 원래 머리와 귀 메시를 수정하지 않습니다.

- [정면·옆·뒤·큰 머리](hood-loose-continuous-2026-10-03.png)
- [아래 정면·아래 옆·아래 뒤·작은 머리](hood-loose-below-2026-10-03.png)

새 안경은 기존 원형·사각 안경을 만드는 동일한 경로를 사용합니다. 기존 브리지, 직선 안경다리와 위치를 그대로 두고 앞 프레임·렌즈만 교체합니다. 선글라스·물방울 선글라스·눈물 원형·눈물 사각의 브리지와 안경다리 좌표가 기존 안경과 0.000001 이내로 일치하는지 검사합니다. 렌즈는 독립된 평면 입체이며 머리 표면에 휘어 붙이지 않습니다.

- [선글라스 정면·옆·단독](sunglasses-original-base-2026-10-03.png)
- [눈물 원형 정면·옆·단독](tear-round-original-base-2026-10-03.png)
- [눈물 사각 정면·옆·단독](tear-square-original-base-2026-10-03.png)

잠옷 모자는 휘어진 중심선을 따르는 단면으로 구성하고 끝과 밑면을 닫았습니다. 끝은 귀를 피해 앞쪽으로 내려오며 자수도 모자 표면에 놓습니다. 닫힌 변의 수와 면 방향, 두상 위의 여유를 verylow·low·smooth에서 검사합니다. [정면·옆·뒤·위 실제 렌더](sleep-cap-fixed-2026-10-03.png).

## 검증

전체 자동 검사 60개 통과. 정수리 위 33개 광선의 겉감 가림, 이마 중앙이 양옆보다 움푹 내려가지 않는지, 안감이 윗면을 뚫고 나오지 않는지 검사합니다. 머리 크기 0.75·1·1.3 및 몸통 크기 1·1.3에서 모션을 바꿔도 목 연결이 몸통 본에 고정되는지 검사합니다. 기존 18종 의상의 기본 팔 자세·소매·몸판 분리, 손과 소품의 접촉, 독립 PMX 파싱 검사도 유지합니다.

실제 Edge 브라우저에서 후드의 앞·옆·뒤·아래와 크기별 렌더, 잠옷 모자의 네 시점, 안경 6종의 앞·옆·단독 렌더를 확인했습니다. worker와 메인 화면의 후드·잠옷 모자·선글라스·눈물 원형 썸네일은 RGBA 채널 차이가 모두 0이었습니다. worker가 없는 환경의 기본 미리보기 18개도 완료됐으며, 색 변경 시 캐릭터 객체를 재사용했습니다.

GLB는 glTF 컨테이너와 8,155,340바이트 출력을 확인했습니다. 옷 부분 색상, JSON 프로젝트 저장·재불러오기, 단독·함께 GIF, 두 캐릭터의 공유 돗자리 검사도 통과했습니다. GIF는 540 × 359px·12프레임, 프레임 간 변화 픽셀 2,520개이며 브라우저 기능 검사에서 예외는 0개였습니다.

## 성능 측정

기준 소스는 이전 배포 커밋 `536c728fc48d119754034daf6548939c8c746616`입니다. 같은 1280 × 900px Headless Edge·ANGLE SwiftShader에서 기본 미리보기, 의상 반복 생성, 꾸미기 미리보기 100개, 재생 중 3초를 측정했습니다. 모델 반복 생성 평균은 첫 생성 1회를 제외한 이후 3회입니다. 다른 자동 검사를 동시에 실행하지 않았습니다.

| 측정 | 이전 | 수정 후 |
| --- | ---: | ---: |
| 후드 캐릭터 반복 생성 평균 | 284.2ms | 54.7ms |
| 잠옷·모자 반복 생성 평균 | 150.9ms | 38.4ms |
| 교복·안경 반복 생성 평균 | 303.4ms | 50.6ms |
| 꾸미기 미리보기 완료 | 24.4초 | 19.1초 |
| 해당 구간 메인 스레드 긴 작업 | 84회 | 2회 |
| 기본 미리보기 완료 | 6.4초 | 5.9초 |

실제 모델·조명·해상도를 공유하는 module worker에서 OffscreenCanvas로 썸네일을 만듭니다. 지원하지 않는 브라우저에서는 메인 스레드 작업을 예약해 같은 렌더러를 사용합니다. 후드의 불변 원형, 의상·조끼·모자의 제한된 캐시와 두상 좌표 질의 재사용을 추가했고 각 캐릭터에는 독립적으로 편집 가능한 지오메트리 복사본을 제공합니다. 부드러운 옷의 공유 정점을 유지해 같은 스킨 변환의 중복도 줄였습니다. 작업용 headless Edge 프로세스 48개가 남아 있던 문제를 정리하고, 검사 종료 시 해당 실행의 프로필·프로세스만 정리하도록 도구를 수정했습니다.

이 측정은 화면을 막던 긴 작업과 반복 생성 시간의 감소를 확인합니다. 지속 FPS 개선은 확인하지 못했습니다. 소프트웨어 렌더링에서 이전은 3.014초 동안 73프레임, 수정 후는 3.0045초 동안 62프레임입니다. 실제 사용자 GPU의 FPS는 측정하지 않았으며 처음 생성하는 새 의상·모자는 여전히 계산 시간이 듭니다. 원자료: [이전](headwear-performance-before.json), [수정 후](headwear-performance-after.json).
